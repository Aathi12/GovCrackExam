# Classification Verification Prompt

Read the file `classification_to_verify.json`. It contains 30 candidate questions for "Classification (Odd One Out)".

Your task is to independently solve and verify at least 15-20 of these questions.
For each question:
1. Determine the common relationship/property that connects exactly 3 of the options.
2. Determine which option does NOT share this property (the odd one out).
3. If it is ambiguous (multiple possible valid rules yielding different answers) or the OCR is corrupted, SKIP IT.
4. If it relies on general knowledge that is missing (e.g. figure based), SKIP IT.
5. Create a concise explanation explicitly stating the rule that 3 share, and why the odd one does not.
6. The correct answer must be the 1-indexed option number (1, 2, 3, or 4).

Format your output as a markdown JSON block containing an array of objects.
Each object must have:
- `question`: The question text (cleaned up, e.g. remove "Ans Question ID..." noise). Example: "Three of the following four letter-clusters are alike in a certain way and one is different. Pick the odd one out."
- `options`: A list of exactly 4 string options (cleaned up).
- `correctOption`: Integer 1, 2, 3, or 4.
- `explanation`: The concise explanation you formulated.
- `subtopic`: "Classification (Odd One Out)"
- `difficulty`: "medium"
- `sourceYear`: 2024
- `sourcePaper`: "SSC CGL QUESTION PAPERS — EXTRACTED TEXT"

Aim to successfully verify 15-20 questions. Ignore the supplied answers in the corpus (if any are implied), and solve it yourself.
